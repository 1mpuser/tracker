# Дневная сводка: зачёт вместо стены крестиков — дизайн

## Мотивация

Недельная сводка уже переделана так, чтобы подсвечивать засчитанное (`2026-08-05-weekly-summary-visuals-design.md`). Дневная осталась в старом виде, и в канале это видно рядом: над переделанной недельной висит дневная с «Сферы — 0 / 6» и шестью `❌` подряд.

Задача: привести дневную сводку к тому же языку. Данные и механика публикации не меняются — меняется только текст.

## Решения (зафиксировано на брейншторме)

- **Помидорки получают ту же рамку зачёта, что в недельной.** Порог тот же — `POMODORO_MIN = 4`.
- **Нулевой день не упрекается.** При нуле помидорок пишется только число, без напоминания, сколько не хватило: в день, который толком не начался, это издевательство.
- **Блок сфер схлопывается, когда закрытых нет.** Отдельного понятия «пустой день» в коде не заводится: правило одно — нет закрытых сфер, нет и списка. Оно само даёт короткий вид для пустого дня.
- **Третьей копии порога не будет.** `buildDaySummary` живёт в том же пакете, что `weekly.helpers.ts`, поэтому `POMODORO_MIN` импортируется оттуда.

## Формат

Обычный день:

```
📅 5 августа 2026, среда

🍅 Помидорок: 6 — день в зачёте
⭐ Оценка: 8/10

Сферы — 2 / 6
✅ Спорт
✅ Финансы
Не тронуты: Личная жизнь / семья, Обучение, Проекты, Нетворкинг

💬 Разобрал бэклог
```

День без единой закрытой сферы:

```
📅 5 августа 2026, среда

🍅 Помидорок: 0
Сферы не тронуты
```

### Строка помидорок

| Условие | Строка |
|---|---|
| `pomodoros >= POMODORO_MIN` | `🍅 Помидорок: 6 — день в зачёте` |
| `0 < pomodoros < POMODORO_MIN` | `🍅 Помидорок: 2 — до зачёта не хватило 2` |
| `pomodoros === 0` | `🍅 Помидорок: 0` |

Форма «не хватило N» одинаково читается при любом N от 1 до 3, поэтому склонения здесь не требуется.

### Блок сфер

- Есть хотя бы одна закрытая: строка-счётчик `Сферы — <закрыто> / <всего>`, затем `✅ <название>` по каждой закрытой, затем `Не тронуты: A, B, C` — если нетронутые есть.
- Ни одной закрытой: весь блок — одна строка `Сферы не тронуты`.
- Категорий нет вообще: блока нет, как и сейчас.
- Названия экранируются существующим `escapeHtml` **и в списке, и в строке «Не тронуты»**: `<` в названии категории иначе сломает HTML-разметку сообщения.

Оценка и комментарий не меняются: есть — печатаются, нет — строки нет.

## Что не меняется

Всё остальное: триггер по закрытию дня, атомарный захват `Day.telegramMessageId`, отправка через `TelegramService.postDaySummary`, недельная сводка, фронтенд. Меняется одна функция и её тесты.

## Тестирование

`backend/src/telegram/telegram.helpers.spec.ts` (дополняется):
- строка помидорок на границах: `0` → только число; `3` → «не хватило 1»; `4` → «день в зачёте»;
- в списке сфер только закрытые, счётчик показывает `закрыто / всего`;
- нетронутые собраны в строку «Не тронуты»;
- все сферы закрыты — строки «Не тронуты» нет;
- ни одна не закрыта — весь блок это строка «Сферы не тронуты», ни одного `❌` и ни одного счётчика;
- категорий нет — блока нет;
- экранирование `<` работает и в списке закрытых, и в строке «Не тронуты»;
- оценка и комментарий по-прежнему печатаются, когда заданы, и отсутствуют, когда нет.

## Живая проверка

Закрыть день из интерфейса и посмотреть на пост в канале: стены крестиков нет, строка помидорок соответствует таблице выше, нетронутые сферы одной строкой.
