# Серия по порогу «≥2 сферы» — дизайн

## Мотивация

С ростом числа категорий (сейчас 6: Спорт, Финансы, Личная жизнь/семья, Обучение, Проекты, Нетворкинг) требование «закрыть ВСЕ сферы за день» для продления серии стало нереалистичным — по факту такой день требует сверхпродуктивности и случается крайне редко. Это убивает мотивацию: пользователь может сделать реально много (закрыть 2-3 сферы), но серия всё равно обнуляется. Нужен более достижимый порог, который действительно отражает «в целом продуктивный день», а не «идеальный день».

## Решение

Порог фиксирован: **день засчитывается в серию, если закрыто ≥2 сферы** (не обязательно все). Это заменяет прежнюю логику «все сферы», а не дополняет её — второго счётчика не будет, старая метрика везде удаляется.

## Изменения

### 1. `lib/streak.ts` — новая семантика

- Экспортируется константа `STREAK_THRESHOLD = 2`.
- `computeStreak` сравнивает `completed >= STREAK_THRESHOLD` вместо `completed === total` — и для дней из истории, и для сегодняшнего live-параметра.
- Прежняя защита от вырожденного `0/0`-дня остаётся ненужной сама по себе (0 никогда не `>= 2`), явный `total > 0` guard убирается как избыточный.

### 2. Шапка (`Header.tsx`)

- Подпись под числом меняется с «дней подряд, все сферы» на «дней подряд, 2+ сферы».
- Новый проп `streakBoosted: boolean` — `Dashboard` вычисляет его как `day.categories.filter(c => c.done).length >= STREAK_THRESHOLD` и передаёт в `Header`. Когда `true`, число серии (`.streakNum`) получает `text-shadow` на основе уже существующего токена `--accent-glow` (тот же приём, что у активного тумблера категории) — сигнал «сегодня уже засчитан в серию». Без текста, только визуальный эффект, живо реагирует на клик по сфере без перезагрузки страницы.

### 3. Новый компонент `StreakHeatmap`

- Рендерится в `StatsPanel`, использует тот же `history` (`GET /history?limit=84`), что и `CategoryHeatmap` — новый API-запрос не нужен.
- Та же 12-недельная Monday-aligned сетка (переиспользует `mondayOffset` из `@/lib/heatmap`), но заливка бинарная: `var(--accent)` если `completed >= STREAK_THRESHOLD`, иначе `var(--panel-alt)` (пусто). Новая тестируемая функция `thresholdHeatmapColor(completed, threshold)` добавляется в `lib/heatmap.ts` рядом с уже существующими `categoryHeatmapColor`/`youtubeHeatmapColor`.
- Под сеткой — подпись: `«{N} из {M} дней с ≥2 сферами ({P}%)»`, где N — число дней в истории с `completed >= STREAK_THRESHOLD`, M — общее число дней в `history`.

## Не входит в объём

- Порог не настраивается пользователем (фиксирован в коде, не в `Settings`).
- Бэкенд не меняется — `HistoryEntry.completed`/`.total` уже достаточно для новой логики.
- `claude_code_prompt.md` (исходная спека) не обновляется — это органическое развитие поверх изначального ТЗ, а не его правка задним числом.
