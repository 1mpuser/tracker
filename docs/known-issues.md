# Известные проблемы

## iCloud Reminders: напоминания не появляются в приложении «Напоминания»

**Статус:** открыт, обнаружен 2026-09-12 на проде. Кодом синка не лечится.

### Симптом

Интеграция iCloud подключена, «Синхронизировать все напоминания» пишет «Обновлено напоминаний: N», в логах бэкенда ошибок нет — а в приложении «Напоминания» (Mac/iPhone) напоминаний `GTD: …` нет.

### Причина

Аккаунт iCloud переведён на «новые» Напоминания (iOS 13+). Для таких аккаунтов Apple не отдаёт настоящие списки через CalDAV: вместо них видна **замороженная копия старого списка** — у нас она называется `Напоминания ⚠️` (значок ⚠️ ставит Apple). Признаки заглушки:

- внутри лежат служебные VTODO самой Apple: «Создатель списка обновил эти напоминания», «Где найти мои напоминания?» (дата создания — момент перевода аккаунта);
- содержимое не совпадает с тем, что показывает приложение (другое число открытых/выполненных).

Трекер пишет в эту заглушку успешно: `PUT` → `201 Created`, объект `gtd-rem-<id>.ics` потом читается обратно. Поэтому ошибок нет, но приложение смотрит в новое хранилище, куда у сторонних сервисов доступа нет.

Календари (VEVENT) через CalDAV работают — интеграция Session это не затрагивает.

### Ловушка при диагностике

`tsdav` `client.fetchCalendarObjects({ calendar })` без `filters` запрашивает только `VEVENT` — на списке напоминаний даёт ложный «0 объектов». Для VTODO:

```ts
filters: [{ 'comp-filter': { _attributes: { name: 'VCALENDAR' }, 'comp-filter': { _attributes: { name: 'VTODO' } } } }]
```

или прямой `GET <calendar.url>gtd-rem-<id>.ics` с Basic-auth (200/404). Но наличие объекта в коллекции **не доказывает**, что он виден в приложении — сверять с самим приложением.

### Варианты исправления

1. **События вместо напоминаний:** писать пункты с эффективной датой (`dueDate` / `scheduledDate` в статусе `calendar`) как VEVENT в отдельный календарь (например, «GTD») с уведомлением. CalDAV для календарей работает.
2. **Напоминания через Telegram-бота:** утренняя сводка «на сегодня + просроченное».
3. **Минимум:** дать отключить только синк напоминаний.

### Сопутствующее

- Подсказка во вкладке «iCloud» («Список «GTD» создайте в «Напоминаниях»») вводит в заблуждение: у переведённых аккаунтов новый список через CalDAV тоже не виден.
- Кнопка «отключить» во вкладке «iCloud» (`clearICloud`) выключает и Session — отключить только напоминания нельзя.
- Проверку списка при подключении (`setICloud`) заглушка проходит: список находится по имени, логин успешен. Стоит распознавать заглушку (служебные VTODO Apple) и предупреждать.
